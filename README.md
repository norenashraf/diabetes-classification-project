## Pipeline

1. **Data Cleaning** — dropped identifier columns, removed duplicates, checked outliers (IQR), fixed inconsistent labels (e.g. `'Y '` vs `'Y'`, `'f'` vs `'F'`)
2. **Feature Engineering** — derived `BMI_Category` (Underweight / Normal / Overweight / Obese) from the raw BMI value
3. **EDA** — univariate, bivariate, and multivariate analysis; HbA1c emerged as the strongest predictor
4. **Preprocessing** — `RobustScaler` for numerical features, `OneHotEncoder` for categorical features, combined via `ColumnTransformer`
5. **Modeling** — compared Logistic Regression, KNN, Decision Tree, Random Forest, and Gradient Boosting via 5-fold cross-validation (accuracy + F1-macro, since the target is imbalanced); tuned the top model with `RandomizedSearchCV`
6. **Deployment** — saved the final pipeline with `joblib` and built a Streamlit app for interactive predictions

## How to Run

1. Clone the repo and install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the notebook `Diabetes_Classification_Full_Project.ipynb` end-to-end to regenerate the cleaned data and trained model files.
3. Launch the app:
   ```bash
   streamlit run Diabetes_Prediction_deployment.py
   ```
4. Open the local URL shown in the terminal (usually `http://localhost:8501`).
